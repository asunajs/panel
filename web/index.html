日志

面板信息

重启进程

改了环境变量（PANEL_TOKEN / PANEL_BIND 这类）才需要重启。配置、插件源码、任务计划都是热生效的，不用重启。

重启方式是 exec 自身：进程号不变，正在跑的任务会中断。

登录会话

登录后浏览器持有一张 HttpOnly 会话票（30 天），令牌本身不存本地、也不进 URL。换令牌会让所有会话立刻失效。

引擎试跑

在一次性上下文里跑一段源码：跑完就扔，不碰任何插件的状态，也不写运行记录。可以用 console.log、host.*、import，以及顶层 await。

config.json

保存后插件立刻读到新值，不用重启面板；配置里可能有凭据，文件按 0600 落盘。

鉴权与暴露面

通知渠道

渠道写在 config.json 的 notify 键里（含 SMTP 凭据，文件是 0600）。这里的「试发」会真的发一条，并在下面的发件箱里留痕。

发件箱

—

外部渠道失败是常态（对端重启、网络抖）。每条通知先落发件箱再投递，失败按 1m / 5m / 15m / 1h / 6h 退避重试，5 次后放弃；放弃的行留在这里，可以手动重试。

数据与目录

需要面板令牌

这个面板启用了令牌鉴权。令牌只保存在本机浏览器，通过请求头发送，不进 URL。
