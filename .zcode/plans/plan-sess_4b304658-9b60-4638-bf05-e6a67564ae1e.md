# 把「手机号 + 获取验证码」做成面板共享控件（p-sms-code）

## Context

截图里的输入格（手机号 + 行内「获取验证码」按钮）目前是 mcloud 插件私有的：`.input-group` 样式在 mcloud `plugins/mcloud/style.css:238`，倒计时/门禁逻辑（`gate` / `startResend` / `stopResend` / `resendTimers`）在 mcloud `plugins/mcloud/app.js:408-457`，短信、App 两个页签各一份。mgmusic 等其他插件将来要发码就得再抄一遍。

面板已有共享控件体系：`web/ui.js` 定义 `p-select` / `p-field` / `p-button` 等自定义元素，插件页引 `/app.css` + `/ui.js` 就能用（活文档是 `plugins/webui-demo.webui/`，门禁是 `scripts/ui-kit-check.mjs`，真浏览器里点一遍）。按此惯例把这一格提为共享控件，mcloud 迁移过去当第一个使用者。

**范围决定**：控件只做「手机号 + 发码按钮 + 重发倒计时」这一格（与截图一致）；验证码输入格留给插件自己（就是个普通 input，布局各插件不同）。

## 控件 API（`p-sms-code`）

```html
<p-sms-code id="sms-send" placeholder="请输入手机号" button="获取验证码" length="11" seconds="60"></p-sms-code>
```

- 结构（沿用 ui.js 的 `build()` 惯例，首次渲染包一层 `div.input-group`）：`input[type=tel]`（只留数字、`autocomplete="tel"`、`inputmode="numeric"`）+ `button.btn`，中间竖线由 CSS 负责。
- 行为：满 `length`（默认 11）位才放开按钮；输入框上 Enter = 点按钮（可点时）；`value` get/set（setter 重算门禁）。
- 事件：`input`/`change`（`detail.value`）；点按钮派 **`send`**（`detail.value`）—— 控件不发请求，发码归插件后端。
- 方法/属性：`startResend(seconds=60)`（倒计时接管按钮 →「重新获取（N 秒）」+ disabled，照搬 mcloud 现有文案与 `dataset.resend` 语义）、`stopResend()`、`busy`（请求期间禁用）、`disabled`。
