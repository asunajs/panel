## 读这张订单要抓住的三件事

1. **不是重构是重写**：基线是原 QuickJS 那一支（`rust-plugin-panel` 的 git HEAD `b252bd0`），
   **不是**它工作树里的 Node-only 迁移。旧契约不写垫片，旧代码有问题就丢。
2. **能用 LLRT 的就别手写**：runtime、fs、crypto、process 这些走引擎自带模块，宿主只补面板语义。
3. **插件跑得久**：20 分钟起步（AWS Lambda 已能配到 90 分钟），所以一次 invocation 一个
   `AsyncRuntime`，CPU 预算而不是墙钟硬超时。
